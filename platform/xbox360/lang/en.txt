# Harissa64 V2 - menu texts, English (the reference: every language has the same keys).
#
# One text per line: KEY = text. "\n" starts a new line. %d (a number) and %s
# (a word or a name) are filled in by the emulator: keep each of them, in the
# same order. Button prompts ("A:Select|B:Back") are button:label pairs
# separated by "|": translate only the labels, never the buttons, and never put
# ":" or "|" in a label. Keep texts about as short as the English ones: the
# menus have fixed widths (tools/gen_lang.py checks them).
#
# After a change: python platform/xbox360/tools/gen_lang.py (writes xb_lang_table.h).

# ---- Descriptions of the settings (the big icons style) ----
SETVIEW = Settings style
VIEW_LIST = List
VIEW_TILES = Big icons
D_ANTIFLICKER = Mixes each picture with the previous one to remove some games' flicker; it may look a little blurry.
D_ART_DOWNLOADS = Downloads box art and game information from the internet.
D_ART_EXTRAS = With downloads on, also fetches pictures from the game, title screens and logos. Off: box art only.
D_AUDIO_MARGIN = How much sound is prepared ahead: higher avoids cuts, lower reduces the sound's delay.
D_AUDIO_OUTPUT = Stereo, or mono: the same sound in both speakers.
D_AUTOSAVE_SLOT = The slot the game is saved to when the controller is unplugged.
D_BATTERY_WARN = Warns when the controller's battery drops below this level.
D_BG_EFFECT = The animated background of the game list and the menus.
D_BLUR = Softens the picture. At 0 % it is off; it is not used together with sharpening.
D_BORDERS = The edges' colour, glow and effect; the panels' colour, transparency and corners.
D_BRIGHTNESS = Lightens or darkens the game's picture. 50 % is as the original console.
D_CATEGORIES = Makes tabs in the game list by genre, region, players or year.
D_CAT_DELETE = Deletes this category.
D_CAT_FIELD = The games' detail the category uses.
D_CAT_NEW = Makes a new tab for the game list.
D_CAT_SAVE = Saves the category.
D_CAT_VALUE = The value the category's games must have.
D_COLOR_STYLE = Changes the picture's colours: saturated, black and white, sepia and more.
D_CONTROLS = Maps the controller's buttons, calibrates the sticks and sets the shortcuts.
D_CPU_NEXT = Recompiler (fast) or interpreter (more compatible). It applies when the next game starts.
D_DESIGN = How the game list looks: list, covers, big covers, carousel, mosaic or spotlight.
D_DEV_MODE = Options to diagnose problems: the graphics log and a quick texture switch.
D_EXPLORER = Copies, moves and organises files between the console and memories.
D_FONT = The menus' font.
D_FXAA = Smooths the picture's jagged edges.
D_FX_RESET = Back to this page's original values.
D_GAME_IMAGES = Which picture each game shows, and its downloads.
D_GFX_LOG = Warning: this mode uses more CPU and RAM. It writes the drawing modes and the textures not found to the log, to look into graphics errors.
D_GRAPHICS = Texture filter, HD textures, smoothing, sharpening and blur.
D_HIRESTEX = Replaces the game's textures with a high definition pack, when there is one for it.
D_IMG_KIND = Each game's picture: box, 3D box, screenshot, title screen or logo.
D_INTERFACE = How the menus look: layout, colours, backgrounds, effects and language.
D_INTRO_WELCOME = Shows the LAIKA 64 logo when the emulator starts.
D_LANGUAGE = The menus' language.
D_MUSIC = The menus' music: in order, at random, one track or none.
D_PAD_LOSS = What to do when the controller is unplugged: nothing, save and pause, or just pause.
D_PATHS = The folders for ROMs, music, screenshots, saves and textures.
D_PERF_OVERLAY = Shows the FPS, CPU use, memory and temperatures on screen.
D_PIC_CAL = The picture's size and position on your TV.
D_PIC_LR = Moves the picture left or right.
D_PIC_SIZE = Brings the game's picture closer or further.
D_PIC_UD = Moves the picture up or down.
D_PRESET = Ready combinations of filter, smoothing, sharpening and screen effect.
D_RESOLUTION = 4:3 resolutions, the N64's own shape. Picking one turns the 16:9 list off. Higher looks sharper but asks more of the console.
D_RSP_NEXT = HLE (fast) or LLE (more accurate) for the coprocessor. It applies when the next game starts.
D_SAVER = The game list's screen saver.
D_SAVER_MODE = What the saver shows: effect, wallpapers, logo or clock.
D_SAVER_PREVIEW = Shows the saver now.
D_SAVER_TIME = Minutes without touching the controller before it starts.
D_SAVE_ALL = Saves these settings for every game.
D_SAVE_GAME = Saves these settings for this game only.
D_SCREEN = Resolution, brightness, sync and screen effects.
D_SCREEN_EFFECT = Imitates the screens of the time: scanlines, CRT, LCD, vignette and more.
